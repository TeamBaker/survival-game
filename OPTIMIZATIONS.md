# Survival Game Optimization List
Generated by Claude Code after reading all 8,227 lines of web/index.html (Oct 2026).
Memory measurements: 76MB per voxel array, ~30M solid blocks, 230,400 columns (480/side, not 960 as the comment says). 61% of voxel store is air.

Status: IN PROGRESS (#1-#10 done). After each change, bump window.GAME_VERSION (line ~9 of index.html) — note: it is no longer `var v`.
